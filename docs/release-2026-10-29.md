# SEO, Analytics and privacy release — 29 October 2026

Status: prepared and checked; neither production hosting target has been published.

## Production application

- `/` renders the existing full storefront with its header, footer and canonical `https://lumeapungilor.ro/`.
- `/magazin` and `/magazin/` permanently redirect to `/`.
- `/contacteaza-ne`, `/contact-us` and `/contacte` permanently redirect to `/contact`; `/despre-noi` redirects to `/despre`. Trailing slashes and query strings are supported.
- Logos, home links, content-preview links and structured breadcrumbs name `/`. The sitemap includes `/` and omits `/magazin`. Canonical and sitemap origins always name the production domain, including when building with the old Lovable `.env`.
- Redirects run before application/database loading, after the existing sensitive-path protection. Unrelated paths retain normal routing. POST bodies are not redirected across domains.
- Analytics measures the root homepage, keeps Google requests gated on consent, excludes private routes and updates the page context for enabled enhanced events after navigation.
- Privacy section 15 explains the enabled events, identifiers, device/approximate location data, consent, cookies, Google processing and withdrawal. Its cookie-settings control opens the existing preferences dialog.
